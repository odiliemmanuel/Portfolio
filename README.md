# Emmanuel (Odili) — Personal Portfolio

A minimalist, dark-themed portfolio website showcasing my software engineering projects, skills, and professional experience. Built with plain HTML, CSS, and JavaScript — no frameworks, no build tools.

**Live:** [odiliejeh.vercel.app](https://odiliejeh.vercel.app)

---

## Sections

| Section | What's inside |
|---------|--------------|
| **Hero** | Name, role, animated typing effect, social links |
| **About** | Bio, location, tech stack organized by category |
| **Projects** | 8 featured projects with category filter (Fintech, EdTech, AI, Full-Stack, Mobile) |
| **Services** | Backend, frontend, mobile, AI/data, DevOps, fintech integrations |
| **Blog** | 4 technical write-ups with content modals |
| **Testimonials** | References from colleagues and mentors |
| **Contact** | Form with validation + direct email link |

## Tech Stack

- **HTML5** — semantic markup
- **CSS3** — custom properties, grid, flexbox, animations, responsive design
- **JavaScript (ES6+)** — vanilla, no dependencies
- **Google Fonts** — Inter (body), Playfair Display (headings), JetBrains Mono (code)
- **Formspree** — contact form backend (optional)

## Design

Dark theme inspired by the [EstateLink](https://github.com/odiliemmanuel/Estate-Link) color palette — deep teal (`#14b8a6`) and ember orange (`#e36414`) with Playfair Display serif headings.

## Run Locally

```bash
git clone https://github.com/odiliemmanuel/Portfolio.git
cd Portfolio
python3 -m http.server 8080
# open http://localhost:8080
```

No build step. No dependencies. Just serve the files.

## Deploy to Vercel

```bash
# Install Vercel CLI if needed
npm i -g vercel

# Deploy
vercel
```

Or import the repo directly on [vercel.com/new](https://vercel.com/new).
